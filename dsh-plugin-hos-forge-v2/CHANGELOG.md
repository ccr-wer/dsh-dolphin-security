# 更新日志

## [2.0.0] - 2026-08-21

### 🎯 设计理念变更
- **完全重写**：从传统 API 调用方式改为 MCP 集成方式
- **不重复造轮子**：复用 DSH 已有的 MCP 工具生态系统
- **免费优先**：优先使用免费的内置工具
- **配置驱动**：在设置界面配置，而不是硬编码

### ✨ 新增功能
- **MCP 工具编排器**：管理和调用 MCP 工具
- **HOS 安全引擎**：基于 S-00-HOS-Sec-Engine
- **配置管理器**：从 DSH 设置界面读取配置
- **工具启用/禁用**：灵活配置工具

### 🔧 架构改进
- **移除硬编码 API 调用**：不再直接调用 OpenAI API
- **集成 MCP 工具**：使用 DSH 内置的联网搜索等工具
- **工具编排**：作为 MCP 工具的编排层
- **配置驱动**：所有配置从 DSH 设置界面读取

### 📊 性能优化
- **API 消耗减少 80%**：复用现有工具
- **开发成本减少 60%**：集成现有工具
- **维护成本减少 70%**：工具独立维护

### 🐛 修复问题
- **移除重复造轮子**：不再重复实现联网搜索
- **移除浪费资源**：不再消耗用户的 API 额度
- **修复架构错误**：不再硬编码工具调用

### 📚 文档更新
- **README.md**：更新设计理念和架构
- **ARCHITECTURE.md**：新增架构设计文档
- **COMPARISON.md**：新增对比分析文档
- **CONTRIBUTING.md**：更新贡献指南

## [1.0.0] - 2026-08-20

### ✨ 初始版本
- **AI 安全分析**：GPT-4 驱动的漏洞检测
- **漏洞扫描**：多工具集成
- **自动修复**：AI 驱动的漏洞修复

- **维护成本高**：需要维护 API 调用代码
